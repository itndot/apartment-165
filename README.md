# Квартира 165 — интерактивный планировщик

Редактор планировки квартиры с мебелью в масштабе, проверкой проходов, сравнением вариантов и историей изменений.

## Возможности

- Редактирование стен, вершин, дверей и подписей помещений.
- Автоматический пересчёт площадей по контурам.
- Мебель с размерами в сантиметрах; исходный стол 200 × 80 см.
- Два начальных варианта кабинета, создание новых вариантов и сравнение.
- Проверка пересечений, открывания дверей и маршрутов из прихожей.
- Снимки истории, отмена/повтор и восстановление отдельной копией.
- Экспорт и импорт всего проекта в JSON, экспорт чертежа в SVG, печать.

Геометрия восстановлена приблизительно по исходным изображениям. До обмеров размеры и проверка проходов являются предварительными.

Изменения сохраняются в браузере на конкретном устройстве. Для переноса на другое устройство или другой домен используйте экспорт/импорт JSON. Серверной синхронизации нет.

## GitHub Pages

Статические файлы находятся в `docs/`; сборка и зависимости не требуются.
В Settings → Pages выберите Deploy from a branch → main → /docs.
Все пути относительные, поэтому сайт работает на проектном адресе GitHub Pages.

## Локальный запуск

```sh
python3 -m http.server 8000 --directory docs
```

Откройте http://localhost:8000.

## Проверки

```sh
node --check docs/app.js
node --test tests/model.test.cjs
```
